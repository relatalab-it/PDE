# JournAI — Phase 5: HTML Publication Page

## Purpose

Produce `reports/NN_slug/index.html`: a self-contained, reproducible HTML page that
documents the analysis, visualisations, methodology and raw data.

Do not write CSS, nav, header, footer, intro section, raw data or methodology sections
directly — these are generated by `initShell()`. Write only the dataset sections and
the JS config.

After each new report, update `reports.json` in the repository root.

---

## Mandatory page structure

The `index.html` must contain in order:

1. **Header** — title, description, badges (provider / period / entities)
2. **Sticky nav** — links to all sections
3. **Intro section** — what is measured, why, scope limits, finding cards (4 key numbers),
   executive summary (`introExtra`)
4. **Section per dataset** — one `<section>` per `output/*.csv` file; no orphaned queries
5. **Raw data section** — licence callout + download cards for each CSV
6. **Methodology section** — classifications, API URLs, CLI commands, files
7. **Footer** — sources, tools, generation date

**Generation date rule**: appears in three places, always as `DD Month YYYY`
(e.g. `18 May 2026`):
- Header eyebrow: `SDMX Research · [DD Month YYYY] · opensdmx CLI`
- Raw data callout: `Extraction date: <strong>[DD Month YYYY]</strong>`
- Last `<span>` in the footer

## Bilingual toggle (opt-in)

The ENG|ITA toggle is available but not the default (Constitution Article 11).
To activate it for a report, record the language instruction in `story-brief.md`
before generating any HTML. When active:

- Every `initShell()` text field must have a `_en` variant (see schema above)
- Every user-visible string in static `<section>` content must be wrapped:
  ```html
  <span class="it">Testo in italiano</span>
  <span class="en">Text in English</span>
  ```
- Set `<html lang="it">` when Italian is primary

Without the explicit instruction in `story-brief.md`, generate English-only HTML
with no `_en` fields and `<html lang="en">`.

## `reports.json` update

After each new report, add an entry:

```json
{
  "order": 2,
  "path": "reports/02_slug/",
  "date": "2026-05-18",
  "title": "Report title",
  "desc": "One-sentence description",
  "badges": ["Eurostat", "2000–2024", "27 countries"]
}
```

The catalogue `index.html` reads this file via `fetch()` — no modification to the
catalogue HTML is needed.
