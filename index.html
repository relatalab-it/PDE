MethodologyMetodologia

How it worksCome funziona

The AI receives a natural language question and drives opensdmx CLI step-by-step. Calculations are performed by the library — not the AI — ensuring that every transformation is correct. Example: European population by country via Eurostat. L'AI riceve una domanda in linguaggio naturale e pilota opensdmx CLI passo-passo. I calcoli sono eseguiti dalla libreria — non dall'AI — garantendo che ogni trasformazione sia corretta. Esempio: popolazione europea per paese via Eurostat.

Dataset search Ricerca dataset

Full-text search on the provider's index. On Eurostat this returns hundreds of datasets; the relevant candidates are selected for subsequent verification. Ricerca full-text sull'indice del provider. 03
Candidate evaluation · 3 parallel info calls Valutazione candidati · 3 chiamate info in parallelo

For each candidate the structure endpoint is queried to verify temporal coverage, geographic granularity and available dimensions. Unsuitable datasets are excluded with explicit justification. Per ogni candidato viene interrogato lo structure endpoint per verificare copertura temporale, granularità geografica e dimensioni disponibili. I dataset non adatti vengono esclusi con motivazione esplicita.

$ opensdmx info DEMO_PJAN → freq · unit · age · sex · geo · 1960–2025 ✓

04
Real code verification · constraint endpoint Verifica codici reali · constraint endpoint

Before downloading data, the real constraints of the dataset are queried: how many values exist for each dimension and which codes are actually available. This prevents building queries with non-existent codes. Prima di scaricare i dati, vengono interrogati i constraint reali del dataset: quanti valori esistono per ogni dimensione e quali codici sono effettivamente disponibili. Questo impedisce di costruire query con codici inesistenti.

05
Download with precise filters Download con filtri precisi

The query is built with the codes verified in the previous step. --last-n 1 selects the most recent observation for each series, avoiding downloading the entire time series when not needed. La query viene costruita con i codici verificati al passo precedente. --last-n 1 seleziona l'osservazione più recente per ogni serie, evitando di scaricare l'intera serie storica quando non serve.

$ opensdmx get DEMO_PJAN --age TOTAL --sex T --last-n 1
↳ most recent observation per series · all countries · 59 raw rowsosservazione più recente per serie · tutti i paesi · 59 righe raw
06
Processing · filter, decode, sort Elaborazione · filtra, decodifica, ordina

Raw data contains aggregated codes (EU27, EA20, EEA…) that must be removed before visualisation. ISO codes are replaced with country names. Each operation is documented and declared in the report. I dati grezzi contengono codici aggregati (EU27, EA20, EEA…) che vanno rimossi prima della visualizzazione. I codici ISO vengono sostituiti con i nomi paese. Ogni operazione è documentata e dichiarata nel report.
