Analysis of Maggioli open data portals via the Opendata Explorer connector

A practical demonstration of how Claude, through the Opendata Explorer MCP connector, can autonomously query, analyse and visualise the entire open data catalogue of a CKAN portal.

Portal analysed: opendata.maggioli.cloud Technology: CKAN 2.10.3 Analysis date: 17 May 2026
§ 01 — Architecture

The Opendata Explorer connector

Opendata Explorer is an MCP (Model Context Protocol) server that exposes to Claude a set of tools to query any CKAN portal and public SPARQL endpoint, without the user needing to know the underlying APIs.

👤 User
→
Claude (AI)
→
MCP: Opendata Explorer
→
CKAN REST API
→
opendata.maggioli.cloud

Claude receives the request in natural language, autonomously selects which tool to call, builds the correct parameters and interprets the response for the user.

§ 08 — Multiportal use case

Road accidents — data extracted across portals

Of 181 organizations on the portal, 6 publish road accident datasets with data queryable via DataStore. Datasets were found with ckan_find_relevant_datasets (query: "incidenti", 116 total results, filtered by relevance), then real data was extracted with ckan_list_resources + ckan_datastore_search.

Portals with road accident data (6 of 181)

Search performed with ckan_find_relevant_datasets — query: "incidenti", weights: title=5, notes=2, tags=3. 116 results returned; the municipalities below have datasets with datastore_active: true, enabling direct API data queries.

Comune di Sassuolo 13 dataset Comune di Maranello 15+ dataset Comune di Formigine 10+ dataset Comune di Fiorano Modenese 5+ dataset Comune di Piacenza serie storica 2022-2024 Comune di Seriate 3.241 record 2000-2013

Note: many other municipalities have Local Police datasets tagged "Polizia Locale 2024/2025" containing accident data, but generically classified under "Governo". Keyword search on the title is the most effective discovery method.
